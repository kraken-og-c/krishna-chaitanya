# YouTube Thumbnail Designer Portfolio

Built with Next.js App Router + TypeScript + TailwindCSS + Framer Motion + Spline embeds.

## Run

```bash
npm install
npm run dev
```

## Structure

- `app/` - Next.js app router pages and global styles
- `components/` - reusable UI and 3D wrapper components
- `sections/` - homepage section modules
- `spline-scenes/` - references for Spline scene ideas
- `styles/` - optional style extension folder
- `pages/` - reserved migration folder if needed
- `assets/` - static media assets
